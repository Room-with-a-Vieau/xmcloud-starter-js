# Booth University College — Variant Selection Checklist

The page components all use **Default**, so nothing needs changing there. Only the partial designs need a variant set:

| # | Component | Current | Needed |
|---|-----------|---------|--------|
| 1 | Header (partial design) | Default | WithLogoImage |
| 2 | Footer (partial design) | Default | WithSocials |

Steps: open the partial design in Pages → click the component → **Design** tab → choose the variant.
